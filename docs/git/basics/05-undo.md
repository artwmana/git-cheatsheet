В Git есть несколько способов отмены, и каждый работает на своем уровне. Важно понимать, хотим ли мы убрать изменения из рабочего дерева, из индекса или из истории коммитов.

Основные команды отмены
- restore Возвращает файл к состоянию из индекса или коммита
- reset Передвигает HEAD и может менять индекс и рабочее дерево
- revert Создает новый коммит, отменяющий изменения старого
- stash Временно убирает незакоммиченные изменения

Частые команды
```bash
git restore <file>
git restore --staged <file>
git reset --soft HEAD~1
git reset --hard HEAD~1
git revert <commit>
git stash
git stash pop
```

Когда что использовать
- `restore` если нужно откатить файл без переписывания истории
- `reset --soft` если нужно убрать коммит, но оставить изменения staged
- `reset --hard` если нужно полностью выбросить изменения
- `revert` если коммит уже опубликован и историю лучше не переписывать
- `stash` если нужно быстро переключиться на другую задачу

Что важно помнить
- `reset --hard` удаляет локальные изменения без возможности простого возврата
- `revert` безопаснее для общих веток
- `stash` сохраняет только незакоммиченные изменения, а не уже отправленные коммиты
