Настройка Git - это первый этап перед работой с репозиторием. Здесь находятся команды для создания репозитория, клонирования проекта и базовой конфигурации пользователя. Обычно этот блок делается один раз на машине, а затем используется по необходимости для новых проектов.

Создание и получение репозитория
- init Создает новый локальный репозиторий в текущей папке
- clone Копирует удаленный репозиторий на локальную машину

Базовая конфигурация пользователя
- config user.name Задает имя автора коммитов
- config user.email Задает email автора коммитов
- config --global Применяет настройку для всех репозиториев пользователя
- config --local Применяет настройку только для текущего репозитория

Полезные команды настройки
```bash
git init
git clone <url>
git config --global user.name "Artem"
git config --global user.email "artem@example.com"
git config --global core.editor "code --wait"
git config --list
```

Частые сценарии
- Начать новый проект локально: `git init`
- Скачать существующий проект: `git clone <url>`
- Проверить текущие настройки: `git config --list`
- Настроить имя и почту перед первым коммитом

Что важно помнить
- `--global` записывает настройки в профиль пользователя
- `git init` не создает удаленный репозиторий, только локальный
- `git clone` сразу настраивает remote с именем `origin`
