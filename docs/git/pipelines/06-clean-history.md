Чистая история упрощает ревью и поддержку проекта. Для этого в Git используют `squash`, `amend` и `interactive rebase`, чтобы убрать шумовые коммиты и сделать историю более понятной.

Основные приемы
- amend Изменяет последний коммит
- squash Склеивает несколько коммитов в один
- interactive rebase Позволяет вручную перестроить последовательность коммитов

Частые команды
```bash
git commit --amend
git rebase -i HEAD~3
git rebase -i main
```

Когда использовать
- `amend` если забыли добавить файл или хотите поправить сообщение последнего коммита
- `squash` если история содержит много мелких промежуточных коммитов
- `rebase -i` если нужно переименовать, переставить или объединить коммиты

Что важно помнить
- Эти операции переписывают историю
- После переписывания уже опубликованной ветки потребуется `git push --force-with-lease`
- Перед чисткой истории полезно убедиться, что никто кроме вас не работает с этой веткой
