Конфликт возникает, когда Git не может автоматически понять, какую версию изменений оставить. Чаще всего это случается при `merge`, `rebase` или `cherry-pick`.

Как выглядит процесс решения конфликта
1. Git сообщает о конфликтных файлах
2. Открываем файлы и выбираем нужный вариант
3. Убираем конфликтные маркеры
4. Добавляем исправленные файлы в индекс
5. Продолжаем merge или rebase

Пример команд при merge
```bash
git merge feature/auth
git status
git add <file>
git commit
```

Пример команд при rebase
```bash
git rebase main
git status
git add <file>
git rebase --continue
```

Конфликтные маркеры в файле
```text
текущая версия
входящая версия
```

Что важно помнить
- Нельзя просто оставить маркеры в файле
- После исправления надо обязательно сделать `git add`
- Во время rebase можно использовать `git rebase --abort`, если нужно отменить процесс
